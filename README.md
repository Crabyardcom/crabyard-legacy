# Crabyard migration archive

Active development has moved to independent repositories in [Crabyardcom](https://github.com/Crabyardcom):

- [crabyard-cli](https://github.com/Crabyardcom/crabyard-cli): Rust CLI and terminal wizard.
- [crabyard-templates](https://github.com/Crabyardcom/crabyard-templates): modular application templates and assistant instructions.
- [crabyard-api](https://github.com/Crabyardcom/crabyard-api): licenses, downloads, and release distribution.
- [crabyard-web](https://github.com/Crabyardcom/crabyard-web): website and installers.
- [crabyard-docs](https://github.com/Crabyardcom/crabyard-docs): documentation.
- [tesign](https://github.com/Crabyardcom/tesign): component library.

This repository preserves the original development history and prior releases. It is not an active build or deployment source. Each component repository has its own source root, CI, and version history.
